# Release 0.37.2 — Карточка «Класс ТСПУ» работает

**Дата:** 2026-11-21

## Что исправлено

### 1. Карточка «Класс ТСПУ» показывается (две причины)

- Функции карточки были объявлены внутри `if (resultsCard) { ... }`. В strict mode
  это блочная видимость: `typeof`-проверка на старте страницы видела `undefined`
  и вызовы молча пропускались. Функции перенесены на уровень `render()`
- При очистке отладочного кода была удалена строка `JSON.parse(res.stdout)` —
  `d` оставался `null`, функция выходила по `if (!d || d.ok !== true) return`

### 2. Классификатор понимает текстовый формат сканера

Сканер `blockcheckw scan -o` пишет текстовый файл с группировкой по протоколам:
```
# HTTPS/TLS1.2 — 8 strategies
--payload=tls_client_hello --lua-desync=...
```
Классификатор теперь разбирает и JSON, и текст.
