# Матрица провайдеров

Публичная матрица «провайдер × тип блокировки × сервис × стратегия × версия».
Отчёты присылаются через issue-шаблон «Отчёт провайдера для матрицы»;
подробности — [PROVIDER-EVIDENCE.md](PROVIDER-EVIDENCE.md).

> Отчёты — снимок на дату и версию приложения. После обновления и повторного
> подбора результат может измениться; стратегии привязаны к линии и DPI-волне.

## Как добавить

1. Обновитесь до актуальной версии (сейчас 0.38.7+).
2. Прогоните проверки и подбор.
3. «Диагностика → 📤 Отчёт для матрицы» или `blockcheckw-helper evidence --markdown`.
4. Создайте issue по шаблону «Отчёт провайдера для матрицы».
