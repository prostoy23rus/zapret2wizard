# Матрица провайдеров: как поделиться результатом

Цель — публичная матрица «провайдер × тип блокировки × стратегия × версия»,
чтобы новые пользователи видели проверенные варианты, а не гадали.

## Как получить отчёт

**В панели:** «Диагностика» → **📤 Отчёт для матрицы** → скопировать текст.

**По SSH:**
```sh
blockcheckw-helper evidence --markdown   # готовый Markdown
blockcheckw-helper evidence --json       # машинный JSON
```

Перед отчётом полезно один раз прогнать проверки нужных сервисов
(«Проверить доступность» или `blockcheckw-helper test preset_youtube`),
чтобы в таблице были свежие статусы и объёмы.

## Что в отчёте и чего нет

Включается: модель роутера, OpenWrt/ядро/архитектура, версия приложения и сканера,
пакет, провайдер/ASN, тип блокировки, включённые сервисы и **выбранные стратегии**,
последние проверки (статус/HTTP/байты/скорость), **количество** доменов в списках,
число геномов и хороших конфигураций.

**Не включается:** содержимое списков доменов (включая пользовательские), IP-адреса,
DNS-запросы, любые персональные данные. Телеметрии нет — отчёт отправляется только
вручную пользователем.

## Как отправить

Создайте issue по шаблону **«Отчёт провайдера для матрицы»** и вставьте отчёт.
Один провайдер/роутер — один отчёт; после обновления стратегий можно прислать новый.

## Ограничения

- у одного провайдера бывают «волны»: статус зависит от времени, поэтому важны дата
  и версия;
- отчёт описывает только IPv4-проверки текущей версии;
- «optimal» в отчёте — это проверенный объём данных, а не гарантия воспроизведения
  любого видео; история важнее одной точки.
