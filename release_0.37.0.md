## Что нового

### 🔬 Классификатор «КЛАСС ТСПУ» провайдера

Порт saitkul/tspu-class-test v2.5: прогон каталога из 34 стратегий (8 групп)
через штатный сканер, вердикт отдельно по TLS 1.2 и TLS 1.3:

- **L0-** — нарезка пробивает без фейков (хватит простого разреза)
- **L0** — обратный порядок пробивает (multidisorder)
- **L2** — нарезка только с фейком
- **особый** — голый фейк / клон-фейк / send-эхо / pos=sld
- **аномалия** — прямой разрез пробивает, обратный собирается

Плюс **одна минимально достаточная рекомендация** — готовая строка для профиля.
Запуск: кнопка «Определить класс ТСПУ» в карточке под сканером (2–5 минут,
служба на это время останавливается и возвращается сторожем).

Логика вердикта проверена на 12 сценариях, включая реальный профиль RouteRich (L0-).

### 🐤 Канарейка: фоновый контроль живости

Curl раз в N секунд (60–3600) через живую службу; история ОК/СБОЙ с ротацией
256 КБ; СБОЙ пишется в журнал событий. Деградация видна ДО того, как пропадёт
YouTube. Пропуск проверок во время подбора/классификации.

- UI: кнопка в карточке класса ТСПУ (🟢/🔴/⏳ + счётчики)
- CLI: `blockcheckw-helper canary_start|stop|status|log`
- init.d: `uci set zapret2wizard.main.canary=1` (по умолчанию выключена)

### 📦 Пресеты: +11 стратегий и «Универсальная лестница»

Новые механики (все поддержаны нашим zapret-antidpi.lua):

- **Клон-фейк** (`tls_client_hello_clone:blob=hs32/33`) — сильный фулинг там,
  где стандартные фейки детектируются
- **Send-эхо** (`send:repeats=2`) — копии hello серверу, шум для DPI
- **Badsum-пара** (`badsum:pos=2:nodrop:repeats=2/4`) + 7-точечный шред — дробилка
- **payload=all** — двухсторонний шред (режется и ServerHello)
- **Двухпакетный hello** (`multisplit:pos=1`) — имитация kyber-браузеров

Новый пресет **«Универсальная лестница»** — профиль, подтверждённый сообществом
на флапающих ТСПУ RouteRich 25.12.6 (наша же прошивка).

### 🛡️ Валидатор: новые предупреждения

- «desync function ... does not exist» — стратегии шли БЕЗ обхода
- «working without bypass» — домен открывается без обхода, вердикт не доказателен

### 🎥 UI: инструкция по узлу googlevideo

В карточке класса ТСПУ — раскрывающаяся инструкция: F12 → Network →
videoplayback → скопировать узел → прогнать классификацию отдельно.

## Ограничения

- Новые механики (клон-фейк, send-эхо, badsum-пара) добавлены в пресеты,
  но не проверены на живом роутере — перед включением в профиль сверьтесь
  с классификатором или прогоните обычный подбор.
- Канарейка по умолчанию выключена (uci main.canary=0) — включается кнопкой
  в UI или через UCI.
