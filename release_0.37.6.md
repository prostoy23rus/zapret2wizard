# Release 0.37.6 — Обновление само доустанавливает модули ядра

**Дата:** 2026-11-22

## Что изменилось

Раньше кнопка «Обновить» привозила только файлы службы, а kmod-пакеты
(`kmod-nfnetlink-queue`, `kmod-nft-queue`) на чистом роутере приходилось ставить
вручную — без них подбор падал (issue #6).

Теперь `cmd_update` после установки файлов:

1. `modprobe nfnetlink_queue nft_queue` и проверяет, что модули реально работают;
2. если нет — запускает `kmods_install` в фоне: apk/opkg, при отсутствии в фиде
   провайдера — официальный фид OpenWrt под точный релиз/target/ядро;
3. после установки поднимает службу, если она не работала;
4. в ответе обновления появляется пометка «Модули ядра доустанавливаются в фоне».

Ход: `blockcheckw-helper kmods_status`, журнал: `/tmp/bcw_kmods.log`.

## Проверено

- Живой роутер: 0.37.4 → 0.37.6 через кнопку, ответ без пометки (модули уже есть),
  kmods_status: nfnetlink_queue=1, nft_queue=1
- busybox ash -n — OK
